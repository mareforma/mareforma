A validated finding sits in the graph. A new agent runs a larger analysis
and gets a different result. Using `contradicts=`, it names the tension
explicitly. Both coexist, neither is overwritten.

"Validated" here means a named human signed off on the finding, not that the
question is settled. The contestation itself surfaces on the derived question
axis,
`question_status` per `frame_id`, which reads `divided` once a contrary-direction
proposition with independent support (support ≥ 1) sits in the same frame.

## Run

```bash
pip install langchain-core
cd examples/03_documented_contestation
python 03_documented_contestation.py
```

## Key pattern

```python
established = graph.query("treatment X")

graph.assert_claim(
    "Treatment X shows no effect (n=1240, p=0.21)",
    classification="ANALYTICAL",
    contradicts=[c["claim_id"] for c in established],
    supports=["cohort_2026_upstream"],
    generated_by="agent/model-b/lab_b",
)
```
